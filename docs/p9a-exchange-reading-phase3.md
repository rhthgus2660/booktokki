# P9-A Phase 3 — 개인 Reading·북로그 공유 계약

## 원본과 공유 이력

- 개인 책, 진도, 북로그의 원본은 각각 `books`, `record_page`/`reading_logs`, `book_notes`다.
- `exchange_reading_note_shares`는 원본 `book_notes.id`를 가리키는 공유 이력만 저장한다.
- 공유 철회와 방 탈퇴는 활성 공유 이력을 닫으며 개인 북로그를 변경하거나 삭제하지 않는다.
- 재공유는 과거 행을 되살리지 않고 새 `id`의 공유 이력을 만든다.
- 개인 북로그 삭제 시 FK cascade로 공유 링크만 제거된다.

## 공개 판정

본문 공개 여부는 `list_exchange_reading_shared_notes`에서만 계산한다.

- 유효한 13자리 ISBN과 `total_pages`가 모두 같을 때만 동일 판본이다.
- 동일 판본의 페이지 북로그는 조회자의 연결 책 `current_page` 이하에서만 열린다.
- 다른 판본 및 페이지 없는 북로그는 조회자의 연결 책이 `done`이고 `current_page = total_pages`일 때만 열린다.
- 연결 책이나 원본이 유효하지 않으면 본문을 반환하지 않는다.
- 잠긴 결과는 본문, 페이지, 원본 작성 시각을 `null`로 반환한다.
- 수동 동일 작품 확인은 감사 행만 만들며 동일 판본 권한을 부여하지 않는다.

## 접근과 신고

- 활성 멤버만 조회하며 초대 대기자·탈퇴자·비멤버는 거부한다.
- 활성 멤버 사이에 차단 관계가 있으면 조회와 새 공유를 거부한다.
- 신고는 실제로 열람 가능한 상대방 공유 기록만 허용하고 원문과 작성 시각 snapshot을 운영자 전용 evidence에 보관한다.
- P5-B에서 배포한 90일 evidence 정리 함수가 그룹 메시지와 공유 북로그 evidence를 함께 정리한다.

## 출시 게이트

- 현재 계정 삭제는 기존 FK cascade를 따른다. 계정 삭제 시 해당 사용자의 개인 책·북로그·공유 링크·신고 메타데이터 및 연결 evidence가 삭제될 수 있다. 별도 보존 정책 확정 전에는 이 동작을 변경하지 않는다.
- Phase 2/3의 iPhone Safari 키보드, 스크롤, 뒤로 가기는 실제 기기에서 별도 검증해야 한다.
