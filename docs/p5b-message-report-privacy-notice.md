# 메시지 신고 개인정보 고지 반영안

- 수집 항목: 신고한 메시지 본문, 메시지 작성 시각, 신고 사유, 신고 당사자 식별자
- 이용 목적: 서비스 안전 신고의 접수, 검토 및 처리
- 접근 주체: 보호된 운영 환경을 사용하는 Founder
- 보존 기간: 메시지 본문과 작성 시각 증거는 신고 접수 후 최대 90일. 정상 자동 정리 시 89일 23시간부터 90일 미만 사이 삭제
- 계정 삭제: 신고자 또는 신고 대상 계정 삭제 시 기존 cascade 정책에 따라 90일 이전에도 신고와 증거가 삭제될 수 있음
- 제공 및 알림: 신고 사실과 증거를 신고 대상 사용자에게 자동 제공하거나 알리지 않음

Cron 실패 시 실제 보존이 90일을 초과할 수 있으므로 매시 watchdog 기록과 Founder의 일 1회 Cron 상태 확인을 운영 계약으로 둔다. 별도 법적 보존 의무나 분쟁 대응 예외는 V1에 구현하지 않았다.
